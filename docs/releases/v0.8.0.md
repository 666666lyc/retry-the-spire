## 中文

同一安装包适配《杀戮尖塔 2》正式版 **v0.111.1** 与 public-beta **v0.113.1**。

- 适配新版联机大厅回调、玩家列表和模组能力握手。
- 支持测试版愚者及 Dread／Blitz 模式，保留原生模式和自定义游戏标记。
- 修复新版 RNG 适配：牌序重掷会推进实际洗牌状态，并保持其他随机流不变。
- 新房间入口快照保存完整原生对局状态与计时；历史恢复使用原生读档流程。
- 保留 v5 外层快照格式、旧数据迁移及多人协议。不能安全解码的数据会保留；完整快照与游戏构建不符时，在放弃现有对局前停止恢复。

验证：两个分支分别完成 Release 构建；同一正式版构建 DLL 在两分支通过 **36/36** 离线检查，实际引擎均为 **45 个 Harmony 补丁成功、0 失败**。已在隔离离线环境验证正式版 Standard／Custom，以及愚者 Standard／Dread／Blitz 的房间重试、连续牌序重掷、遭遇重掷、原生快照历史恢复及落盘入口 RNG／计时。

仍待验收：双端 Steam 联机、可见 UI、新模式缺少完整快照时的整局历史重建，以及真实跨设备云同步。完整快照不能跨游戏构建互换；多人玩家须使用相同游戏版本。

安装：下载 `RetryTheSpire-v0.8.0.zip`，解压到游戏 `mods` 目录，禁用原版 Retry；或等待 Steam 创意工坊更新。安装包仅含 DLL、清单、许可证和安装说明。

## English

One package supports *Slay the Spire 2* main branch **v0.111.1** and public-beta **v0.113.1**.

- Adapt the multiplayer lobby callbacks, connected-player roster, and mod capability handshake.
- Support the Fool and Dread/Blitz modes while preserving native mode and custom-game flags.
- Advance the actual shuffle RNG state during draw-order rerolls, leaving other random streams unchanged.
- Capture complete native room-entry run state and timing, and restore it through the game's saved-run loader.
- Preserve the v5 outer snapshot format, legacy migration, and multiplayer protocol. Retain incompatible data; stop mismatched-build snapshot restores before abandoning an existing run.

Validation: Release builds succeed against both branches. The same main-branch DLL passes **36/36** offline checks on each branch and loads **45 Harmony patches with zero failures** in both actual game engines. Isolated offline smoke tests cover main-branch Standard/Custom and the Fool in Standard/Dread/Blitz: exact room reloads, consecutive shuffle rerolls, encounter rerolls, native-snapshot history restores, and persisted room-entry RNG/timer state.

Still pending: two-client Steam multiplayer, visible UI checks, complete history reconstruction without native snapshots in the new modes, and real cross-device cloud sync. Native snapshots are specific to their game build; multiplayer peers must use matching game versions.

Installation: extract `RetryTheSpire-v0.8.0.zip` into the game's `mods` directory and disable the original Retry mod, or receive the Steam Workshop update. The package contains only the mod DLL, manifest, license, and installation guide.
